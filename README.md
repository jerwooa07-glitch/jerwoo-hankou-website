## GitHub 更新方式
1. 解壓縮本 ZIP。
2. 打開資料夾，Ctrl+A 全選「裡面的所有檔案與資料夾」。
3. GitHub repository：jerwoo-hankou-website → Add file → Upload files。
4. 把內容拖入 GitHub 根目錄，不要把外層資料夾一起拖進去。
5. 確認能看到 /index.html、/hat-care.html、/assets/...。
6. Commit changes。
7. 等 GitHub Pages 約 1～3 分鐘重新部署。
8. LIFF 不用重新設定，原本 LIFF 會自動讀到新版網站。
